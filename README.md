# SolFrag

SolFrag is a fast-paced, browser-based first-person shooter that brings competitive multiplayer action directly to your web browser. Built with blockchain technology, it combines the thrill of classic FPS gameplay with Web3 features.

## 🎮 Play Now

**Ready to jump in?** Head over to **[solfrag.codepankaj.tech](https://solfrag.codepankaj.tech)** and connect your **Phantom wallet** to start playing!

## About the Game

SolFrag delivers smooth, responsive gameplay with real-time multiplayer combat. Jump into matches instantly—no downloads required. The game features:

- **Instant Play**: Launch and play directly in your browser
- **Multiplayer Action**: Compete against players in real-time
- **Blockchain Integration**: Built on Solana for secure, decentralized gaming
- **Smooth Performance**: Optimized for fast-paced FPS action
